# МЕРА / FurnitureCalc

Тестовый калькулятор мебельного заказа. Python-ядро выполняется в браузере через WebAssembly. Данные сохраняются в браузере пользователя.

Render Static Site: команда сборки `python3 tools/build_render.py`, каталог публикации `dist`.

В репозитории только код и обезличенные учебные данные.
